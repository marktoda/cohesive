## Remaining ambiguity

- **Does promoting four convention-layer greps weaken the substrate-collapse trade-off?** The original collapse demoted four invariants on the bet that wording would stabilize before tests. This pass adds tests (greps) without renaming the rules as invariants. The spec-cohesion reviewer should judge whether this is the right shape (convention + grep) or whether a third tier ("convention with structural pin") deserves a name.
- **Audit-substrate's Hard Constraint #1 rewrite is normative.** The skill now asks a forced-choice question; previously it auto-detected from session memory. This is the intended pattern per `soft-prereqs.md`, but it changes user behavior in direct invocations. Reviewer should confirm the new pattern is correct.
- **The skill-section-presence matrix shows `validate-rewrite` had a missing canonical section.** Adding "What this skill is *not*" was a small drive-by fix surfaced by the matrix. Reviewer should flag if the section's content is wrong or missing entries.
- **The artifact-placement matrix asserts row-A precedence over row-B.** Repos with both `docs/history/` and `docs/adr/` resolve as row A. This is a judgment call; an alternative (prefer the host-repo convention) is also defensible. Reviewer should confirm.
